Design system

Start the web app and open the living style guide. For a separate development stack, use its web port.

Token roles

Primitives
Light and dark palettes, a 4 px spacing base, six Inter type steps, corners, shadows and motion.
Semantic roles
Canvas, surface, raised surface, text, divider, control boundary, focus, action, danger and selected state. The control boundary is stronger than the divider.
Component roles
Table rows, filter chips, overlays, status and map controls use semantic roles. Map colours, chart series and the logo have separate groups.

Density

Density and colour theme can be set independently. Primary touch targets stay at least 44 CSS px on the web and 48 logical px in the field app.
